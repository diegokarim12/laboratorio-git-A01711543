**¿Qué parte de la práctica te resultó más confusa y cómo la resolviste?**  
La parte más confusa fue comprender el flujo para resolver un conflicto de fusión (*merge conflict*) en el archivo `README.md` cuando hubo cambios simultáneos. Lo resolví usando la herramienta visual de VS Code (`Accept Both Changes`) para integrar la propuesta de ambas partes, seguido de realizar el `git add`, `commit` y `push` correspondientes.

Lo usaremos para guardar y organizar todos los bocetos, diseños e investigación en las carpetas de docs/ux y docs/ui. Así todo el equipo sabrá dónde encontrar los archivos más recientes, evitaremos perder trabajo y podremos ver cómo va evolucionando el diseño del proyecto paso a paso.
