# Notas de aprendizaje - Git y GitHub

1. Entendí el ciclo básico de trabajo: modificar archivos, prepararlos con git add, registrarlos con git commit y subirlos a la nube con git push.
2. Aprendí que la zona de preparación (staging area) sirve para seleccionar exactamente qué cambios queremos incluir en cada commit.
3. Comprendí la diferencia entre un repositorio local (en mi computadora) y un repositorio remoto (en GitHub).
4. Descubrí que los commits sirven como historial de fotografías del proyecto para rastrear quién hizo cada cambio y cuándo.
